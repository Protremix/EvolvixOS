Deployment

Get Started in 3 Minutes

Run EvolvixOS entirely on your local machine or private server.

1
Install Ollama
curl -fsSL https://ollama.com/install.sh | sh && ollama run llama3
2
Clone EvolvixOS
git clone https://github.com/evolvixos/evolvixos.git && cd evolvixos
3
Start It
./setup.sh
