# EvolvixOS UI Libraries

Integrated open-source component libraries for AI-assisted frontend design:

## Magic UI (338 components)
- Source: https://github.com/magicuidesign/magicui
- 338 React/TypeScript animated components
- Built with Tailwind CSS & Framer Motion

## Unlumen UI (59 components)
- Source: https://github.com/leovvx/unlumen-ui-docs
- Animated React components for shadcn projects

## Retro UI (53 themes)
- Source: https://github.com/NovusGFX/retro-design-system
- 53 retro HTML/CSS themes: Win95, Vaporwave, GameBoy, Tron, CRT, DOS, etc.

## NVIDIA Nemotron Models
- nemotron-340b, nemotron-70b, nemotron-nano-8b, nemotron-mini-4b
- Available via HuggingFace Inference API Gateway (port 3010)

## Laguna XS 2.1
- 33B MoE, 3B active params, Apache 2.0
- Agentic coding model by Poolside
- Available via Ollama (laguna-xs-2.1)
