🏗️ How It Works

A Platform Built in Layers

EvolvixOS is built on a proven layered architecture — entity-based data, auto-generated APIs, and an AI-driven engineering layer, all on your own infrastructure.

1

Entity Layer — Define Your Data

JSON schemas become PostgreSQL tables instantly. Auto fields: id, created_date, updated_date, created_by.

PostgreSQL
2

API Layer — Auto-Generated CRUD

Every entity gets instant REST endpoints with pagination, sorting, filtering, and row-level security.

FastAPI
3

Workbench Layer — AI-Powered Engineering

Describe your system in natural language. The Workbench creates schemas, pages, and functions automatically.

Local LLM
4

AI Layer — 281 Models, One Router

Intent-based ModelRouter auto-selects the best engine: Groq for fast chat, Gemini for vision, SDXL for images.

ModelRouter V10
5

Media Layer — Full-Stack Production

4K video, AI voiceovers, 3D logos, and cinematic content — all from a single prompt via ffmpeg + Blender + SDXL.

ffmpeg + SDXL
6

Automation Layer — Workflows & Triggers

Schedule tasks, trigger on entity changes, orchestrate multi-step workflows. Visual builder with connector support.

CNCF SWF
7

Security Layer — Hardened by Default

JWT auth, OTP verification, 58 security patterns, XSS/SSRF/injection protection, audit logging, credit-based billing.

350+ Tests
📦 What's Inside

Built for Real Engineering

EvolvixOS isn't a wrapper around someone else's API. It's a complete, self-contained platform you can run, modify, and own. Every line of code is yours.

🛠️ Developer Experience

Everything you need to engineer and ship AI-powered systems without fighting infrastructure.

  • Auto-generated TypeScript & JavaScript SDKs from entity schemas
  • Deploy Python code as HTTP backend functions in one command
  • Visual page builder with drag-and-drop components and live preview
  • Public service viewer — share your services with anyone via URL
  • One-click engineering templates for common patterns (API Gateway, ML Pipeline, Auth Service)
  • API documentation auto-generated for every entity

🤖 Agent Capabilities

Mr. James — the built-in AI agent — has 44 tools and can autonomously build, deploy, and manage.

  • 217 subagent templates across 16 categories (engineering, marketing, security)
  • 16 MBTI personality profiles for customized interaction styles
  • Voice command processing (Alexa-level, smarter)
  • Self-improvement capabilities with self-correction
  • GitHub Discovery Engine — automatically learns new tools
  • Tencent Cloud, Google Gemini, Groq, and Kimi integrations built-in

🔒 Security & Privacy

Built with security-first principles. Every endpoint is protected, every pattern is checked.

  • JWT authentication with OTP verification (Brevo email delivery)
  • 58 dangerous pattern detection (command injection, SSRF, XSS)
  • 25 Python-specific dangerous import blocks
  • SSRF protection with GCP/Azure/AWS metadata endpoint blocking
  • 152 fuzzing tests covering chained and complex attack vectors
  • Three privacy modes: LOCAL (fully offline), HYBRID, CLOUD

🌐 Ecosystem & Integrations

Connect EvolvixOS to your existing tools and services out of the box.

  • WhatsApp & Telegram bot integrations for partner-style interaction
  • Tencent Cloud SDK (CVM, CDB, VPC, SSL, DNS, CDN, Hunyuan AI)
  • TIMSDK for real-time messaging (1,000 MAU free tier)
  • TencentDB Agent Memory Hub for persistent team memory
  • CubeSandbox MicroVM isolation for untrusted code execution
  • Octop AI assistant integration with 217 subagent templates
