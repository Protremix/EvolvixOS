How It Works

A Platform Built in Layers

EvolvixOS is built on a proven layered architecture — entity-based data, auto-generated APIs, and an AI-driven engineering layer, all on your own infrastructure.

1

Entity Layer — Define Your Data

JSON schemas become PostgreSQL tables instantly. Every entity gets auto-generated CRUD APIs with pagination, sorting, filtering, and row-level security. No ORM boilerplate, no migrations to manage.

2

Function Layer — Deploy Logic

Write Python code and deploy it as an HTTP endpoint in one command. Backend functions run server-side with full access to entities, file storage, and external APIs. Auto-scaled and monitored.

3

Workflow Layer — Automate Everything

Schedule recurring tasks, trigger on entity changes, or fire on connector webhooks. Build complex multi-step workflows with conditions, waits, and AI-driven steps — all with a visual builder.

4

AI Layer — Build with Intelligence

Describe what you want in natural language. Mr. James — the built-in AI agent — creates entities, deploys functions, builds pages, and manages your entire stack autonomously using 44+ tools.

How Credits Work

Simple, Usage-Based Credits

Credits are the universal currency on EvolvixOS. Use them for AI chat, function calls, media generation, and more. Different models cost different amounts.

How Credits Work

  • Each AI model has a per-call credit cost
  • Simple models cost 1-2 credits, advanced models 5-20
  • Credits never expire (token packs)
  • Monthly credits refresh each billing cycle

What Costs Credits

  • AI chat (per message based on model)
  • Backend function calls (agent tasks)
  • Image generation (per image)
  • Voice synthesis (per minute of audio)
  • Video generation (per second of video)
